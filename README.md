# Ou Meul Stock

Stock-taking, variance, ordering, waste, daily and staff app for Ou Meul Pinelands. Static web app (HTML/CSS/JS) + Firebase Auth + Firestore, hosted on GitHub Pages.

- `index.html`, `css/`, `js/` — the app
- `firebase-config.js` — paste the Firebase web config here
- `firestore.rules` — paste into Firebase → Firestore → Rules
- `docs/MANUAL.md` — user manual (Dylan and staff)
- `docs/SETUP-GUIDE.md` — installation / hand-over
- `data-folder-template/` — folder structure for Dylan's PC
- `tests/` — optional automated smoke test (`npm i playwright`, then `node tests/smoke.test.js`)
